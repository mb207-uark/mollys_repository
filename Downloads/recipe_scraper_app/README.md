# Flask Recipe Scraper Web App

A simple Python Flask application that scrapes recipe titles and ingredients from URLs.

## Project Structure
```text
recipe_scraper_app/
├── app.py
├── requirements.txt
├── README.md
└── templates/
    └── index.html
```

## How to Run Locally
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open your browser and go to `http://127.0.0.1:5000`
