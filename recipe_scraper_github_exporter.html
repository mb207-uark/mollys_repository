      Pushing This Web App to GitHub

      Step-by-step instructions to host your recipe app on GitHub Pages.

      1

      Download Source Code

      Click the Download App (.zip) button above to get the complete repository package containing index.html, README.md, and LICENSE.

      2

      Create a New GitHub Repository

      Go to GitHub, create a new public repository (e.g., named recipe-scraper-app).

      3

      Push Files via Git Terminal

      Open your terminal inside the unzipped folder and run:

      git init

      git add .

      git commit -m "Initial commit: Recipe Scraper web app"

      git branch -M main

      git remote add origin https://github.com/yourusername/recipe-scraper-app.git

      git push -u origin main

      4

      Enable GitHub Pages (Instant Free Hosting)

      Go to your repository settings on GitHub, navigate to Pages, select the `main` branch under Build and Deployment, and save! Your web app will be live at https://yourusername.github.io/recipe-scraper-app.
